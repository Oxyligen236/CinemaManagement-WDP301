### b. Table / Collection Description

| No | Collection | Description | Primary Key / Indexes | References |
|---|---|---|---|---|
| 01 | `branches` | Stores cinema branch locations, contact metadata, and operational status; supports multi-branch tenant partitioning across auditoriums, staff, and inventories. | • `_id` (PK)<br>• `branchId` (Unique)<br>• `branchName`<br>• `branchStatus` | None |
| 02 | `rooms` | Manages physical auditoriums/screening rooms belonging to specific cinema branches; maintains operational availability and room layout boundaries. | • `_id` (PK)<br>• `roomId` (Unique)<br>• `branchId`<br>• `roomStatus` | • `branchId` -> `branches.branchId` |
| 03 | `seats` | Defines physical seat configurations within auditoriums; tracks row/column coordinates, seating tiers, and operational states for seating grid rendering. | • `_id` (PK)<br>• `seatId` (Unique)<br>• `{ roomId, rowPosition, columnPosition }` (Compound Unique)<br>• `{ roomId, status }` | • `roomId` -> `rooms.roomId` |
| 04 | `movies` | Maintains movie catalog metadata, media keys (posters, trailers), duration, release schedules, and lifecycle states (Coming Soon, Now Showing, Ended). | • `_id` (PK)<br>• `movieId` (Unique)<br>• `movieName`<br>• `{ status, isActive }` | • `genreIds` (Array) -> `genres.genreId` |
| 05 | `genres` | Standardized genre taxonomy records; used for categorizing movie titles and enabling search/filter criteria. | • `_id` (PK)<br>• `genreId` (Unique)<br>• `genreName` | None |
| 06 | `showtimes` | Schedules movie screenings within auditoriums at defined time windows; embeds dynamic pricing rate structures (`seatPriceSelections`, `dayPriceSelections`). | • `_id` (PK)<br>• `showtimeId` (Unique)<br>• `startTime`<br>• `{ movieId, startTime }`<br>• `{ roomId, startTime, endTime }` | • `movieId` -> `movies.movieId`<br>• `roomId` -> `rooms.roomId`<br>• `seatPriceSelections[].ruleId` -> `seat_price_rules.ruleId`<br>• `dayPriceSelections[].ruleId` -> `day_price_rules.ruleId` |
| 07 | `seat_showtimes` | Tracks real-time runtime seat availability per screening session (Empty, Reserved, Booked); powers concurrency seat lockouts during booking. | • `_id` (PK)<br>• `seatShowtimeId` (Unique)<br>• `{ showtimeId, seatId }` (Compound Unique)<br>• `{ showtimeId, seatStatus }` | • `showtimeId` -> `showtimes.showtimeId`<br>• `seatId` -> `seats.seatId` |
| 08 | `seat_price_rules` | Defines rate adjustments and price surcharges configured by seat tier (Standard, VIP, Couple) for dynamic ticket calculation. | • `_id` (PK)<br>• `ruleId` (Unique)<br>• `seatType` | None |
| 09 | `day_price_rules` | Defines rate adjustments and price surcharges configured by calendar day classification (Weekday, Weekend, Holiday). | • `_id` (PK)<br>• `ruleId` (Unique)<br>• `dayType` | None |
| 10 | `items` | Manages discrete concession SKU units (popcorn, beverages, snacks) per branch; tracks stock levels, cost pricing, retail pricing, and reorder thresholds. | • `_id` (PK)<br>• `itemId` (Unique)<br>• `branchId`<br>• `category`<br>• `status`<br>• `{ branchId, status }`<br>• `{ branchId, category }`<br>• `{ branchId, name }` | • `branchId` -> `branches.branchId` |
| 11 | `combos` | Manages bundled concession combo packages offered per branch; embeds composite BOM recipes via `items: ComboItemRef[]`. | • `_id` (PK)<br>• `comboId` (Unique)<br>• `branchId`<br>• `status`<br>• `{ branchId, status }`<br>• `{ branchId, name }` | • `branchId` -> `branches.branchId`<br>• `items[].itemId` -> `items.itemId` |
| 12 | `products` | General merchandise catalog per branch; maintained for standalone auxiliary retail products. | • `_id` (PK)<br>• `productId` (Unique)<br>• `{ branchId, status }`<br>• `productName` | • `branchId` -> `branches.branchId` |
| 13 | `users` | Manages user credentials, authentication version tokens, assigned roles (User, Staff, Manager, Admin), and staff job assignment metadata. | • `_id` (PK)<br>• `userId` (Unique)<br>• `email` (Unique)<br>• `branchId`<br>• `{ role, isActive }`<br>• `{ branchId, role, isActive }` | • `branchId` -> `branches.branchId` |
| 14 | `work_schedules` | Defines shift timetables planned at branch venues and maps allocated staff personnel arrays (`userIds[]`). | • `_id` (PK)<br>• `scheduleId` (Unique)<br>• `{ startTime, endTime }`<br>• `userIds` (Multikey) | • `branchId` -> `branches.branchId`<br>• `userIds` (Array) -> `users.userId` |
| 15 | `shift_attendances` | Records operational employee clock-in/out timestamps and attendance statuses against scheduled shifts for payroll auditing. | • `_id` (PK)<br>• `attendanceId` (Unique)<br>• `{ userId, scheduleId, date }` (Compound Unique) | • `scheduleId` -> `work_schedules.scheduleId`<br>• `userId` -> `users.userId`<br>• `branchId` -> `branches.branchId` |
| 16 | `orders` | Central transactional header entity aggregating ticketing admissions and concession line items, order totals, and payment status lifecycle. | • `_id` (PK)<br>• `orderId` (Unique)<br>• `branchId`<br>• `{ userId, createdAt }`<br>• `status` | • `userId` -> `users.userId`<br>• `promotionId` -> `promotions.promotionId`<br>• `branchId` -> `branches.branchId` |
| 17 | `seat_orders` | Ticketing purchase line item capturing selected seat allocations and locked sale prices at transaction time. | • `_id` (PK)<br>• `seatOrderId` (Unique)<br>• `orderId`<br>• `seatShowtimeId` | • `orderId` -> `orders.orderId`<br>• `seatShowtimeId` -> `seat_showtimes.seatShowtimeId` |
| 18 | `product_orders` | Concession purchase line item tracking ordered SKU/combo quantities and unit prices for stock deduction and F&B accounting. | • `_id` (PK)<br>• `productOrderId` (Unique)<br>• `orderId`<br>• `productId` | • `orderId` -> `orders.orderId`<br>• `productId` -> `items.itemId` / `combos.comboId` / `products.productId` |
| 19 | `tickets` | Issued electronic admission passes generated post-payment; maintains verifiable secure ticket codes (QR), status, and gate scan audit trail. | • `_id` (PK)<br>• `ticketId` (Unique)<br>• `ticketCode` (Unique)<br>• `orderId`<br>• `seatShowtimeId`<br>• `ticketStatus` | • `orderId` -> `orders.orderId`<br>• `seatShowtimeId` -> `seat_showtimes.seatShowtimeId`<br>• `scannedBy` -> `users.userId` |
| 20 | `payments` | Records payment transaction attempts, payment providers (VNPay, MoMo, Cash, Credit Card), external reference IDs, and gateway settlement results. | • `_id` (PK)<br>• `paymentId` (Unique)<br>• `orderId`<br>• `status` | • `orderId` -> `orders.orderId` |
| 21 | `promotions` | Configures marketing promotional campaigns, voucher codes, discounts (percentage or fixed amount), order thresholds, and operational limits. | • `_id` (PK)<br>• `promotionId` (Unique)<br>• `promotionCode` (Unique)<br>• `{ startDate, endDate, isActive }` | None |
| 22 | `promotion_usages` | Redemption ledger tracking customer voucher usage against orders; enforces per-user promotion redemption caps. | • `_id` (PK)<br>• `usageId` (Unique)<br>• `promotionId`<br>• `userId`<br>• `orderId`<br>• `{ promotionId, userId }` (Unique) | • `promotionId` -> `promotions.promotionId`<br>• `userId` -> `users.userId`<br>• `orderId` -> `orders.orderId` |
